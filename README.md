# 🏀 投篮姿态分析

手机浏览器里运行的投篮姿态分析工具：上传侧面投篮视频，自动识别人体骨架并叠加播放。视频**只在本地浏览器处理，不上传任何服务器**。

## 功能

- 手机/电脑选择或拍摄视频
- MediaPipe 姿态识别（33 个关键点），逐帧扫描
- 播放时叠加：骨架、关键点、肘/膝实时角度
- 自动选择面向镜头的一侧（侧面机位）
- 自动检测出手周期（支持一段视频多次出手）：站姿 → 下蹲 → 出手 → 跟随动作；逐次计算后**逐指标取中位数**，更准也更稳（同视频重复分析评分不再漂移）
- 侧面指标 10 项：下蹲膝角、举球肘角、出手肘伸展、出手方向角、出手高度、跟随动作、躯干倾斜、头部晃动、重心横移、起跳（按类型评判）；其中下蹲膝角、出手方向角、出手高度、躯干倾斜的评分区间已按投篮科研实测数据校准
- 跳投 / 罚球 / 三分三种标准切换（罚球要求贴地发力，跳投/三分要求起跳）
- 0–100 评分 + S/A/B/C/D 评级 + 按重要性排序的「问题与原因」（含实测值；点击建议卡可回看视频里出问题的瞬间）
- 多人同框自动锁定主人公（位置 + 体型双因子跟踪），路人不干扰分析；主人公离开画面时冻结等待、绝不把锁交给旁人
- 人物离场/遮挡的空档不会伪造出手：出手候选必须有真实骨架支撑，站姿基线只取真实帧；无法测量的出手计入「未计入」并在报告中说明原因
- 投篮类型默认自动识别（按是否起跳区分罚球/跳投类），也可手动选跳投/中投/三分/罚球
- 个人资料（身高/体重/年龄）存本机浏览器，显示在报告中，不离开设备
- 多角度分析：自动判别机位（侧面/正面/斜侧），报告附「补拍建议」和俯视机位示意图；正面指标 3 项（肘内外展、双脚站距、左右重心偏移）
- 多视频融合：补拍其他机位上传，每个指标自动取最合适的机位，合并成一份完整报告（每项标注来源机位）
- 双视频对比：上传教练/球星参考视频，DTW 逐帧对齐同步播放 + 逐关节偏差分析
- PWA：添加到手机主屏幕当 App 用；二次访问离线可用（模型已缓存）
- 测量按视频宽高比校正：竖屏手机视频的角度/距离不再失真
- HEVC(H.265) 视频自动识别：微信高清视频解不了码时直接说明原因，并给出免费解决办法（VLC / 格式工厂 / iPhone 兼容模式）

## 本地运行

这是纯静态网站，**必须用 `http://` 方式打开**——直接双击 `index.html` 会因 ES 模块限制整体失效（页面会显示红色警告条）：

**方式 A：双击启动脚本（最简单）**
双击项目文件夹里的 `启动本地测试.bat`：自动启动本地服务器并打开浏览器。
它跑的是 `node server.mjs`（零依赖）；想停服务器就关掉最小化的 "shot-analyzer-server" 窗口。

**方式 B：命令行**
```bash
node server.mjs         # 需要装过 Node.js，然后打开 http://127.0.0.1:5500/
# 或
npx -y serve .
# 或
python -m http.server   # 需要装过 Python
```

**方式 C：VSCode Live Server 插件**
安装 "Live Server" 插件后，右键 `index.html` → "Open with Live Server"。

本地开发模式（server.mjs）会屏蔽 `sw.js`，不注册 Service Worker——改完代码刷新即是最新，不会被旧缓存坑到。

识别模型与推理引擎（约 25 MB）已随站点**自托管**（`model/` + `vendor/`），首次打开从本站下载——国内手机网络也能直连，无需访问国外 CDN；之后由 Service Worker 缓存，离线可用。

## 部署到手机可访问（免费）

**方式一：git 命令行（推荐——本机仓库已提交好，两条命令即可推）**
```bash
cd shot-analyzer
git remote add origin https://github.com/<你的用户名>/shot-analyzer.git
git push -u origin main
```
推送时浏览器会弹 GitHub 授权窗，点一下即可。然后开 Settings → Pages → Branch 选 `main` / root → Save，约 1 分钟后访问 `https://<你的用户名>.github.io/shot-analyzer/`。手机浏览器打开 → 分享/菜单 → "添加到主屏幕"，即可像 App 一样离线使用。

**方式二：GitHub 网页上传（不装任何工具）**
1. 注册/登录 GitHub → 右上角 + → New repository，名称如 `shot-analyzer`，选 Public → Create
2. 在空仓库页点 "uploading an existing file"
3. 把本项目**所有文件**（保持文件夹结构）拖进上传区 → Commit changes
   （最大单文件是 `vendor/wasm/` 下两个约 9.4 MB 的 WASM，均在网页上传 25 MB 上限内）
4. 仓库 Settings → Pages → Branch 选 `main` / root → Save
5. 约 1 分钟后访问 `https://<你的用户名>.github.io/shot-analyzer/`

## 拍摄建议（直接影响识别质量）

- 手机固定不动（靠墙/支架），位于投篮者**侧面**（垂直于出手方向），不要手持跟拍
- 全身入镜（头顶到脚都可见、占画面高度一半以上），画面中只有一个人
- 光线充足均匀、不逆光，背景干净，拍摄中不要变焦
- 一段视频包含 **1–5 次完整出手**效果最好（系统逐次检测、取中位数）；每次出手之间站直停顿 1–2 秒
- 时长 3–30 秒（更长只分析前 30 秒）；60fps 更佳

## 路线图

- **M1**：上传视频 + 骨架叠加播放 + 基础角度 ✅
- **M2**：投篮周期检测、生物力学指标、评分与中文报告 ✅
- **M3**：参考视频 DTW 对比、PWA 离线、部署指引 ✅
- **M4**：机位自动判别、补拍建议与机位示意图、正面指标、多视频融合报告 ✅

## 已知限制

- 视频编码需浏览器支持：HEVC(H.265)（微信高清视频常用）在缺解码器的浏览器上无法分析，应用会检测出来并给出免费转换办法
- 出手瞬间球/手移动极快，建议 60fps 拍摄、光线充足、手机固定
- 单机位存在视角盲区（侧面看不到肘内外展/左右对称，正面看不到矢状面指标）；应用会自动判别机位并提示补拍，多视频融合可补全
- 参考对比需要用户自备参考视频（教练示范或球星片段），应用不内置盗版素材
- 手机浏览器推理约 15–30 fps，5 秒视频分析约需 10–30 秒
