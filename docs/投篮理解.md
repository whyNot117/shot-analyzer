# 我的投篮理解（用户笔记 · 2026-10-28）

> 这是本站作者自己的投篮知识体系与个人检查清单。分析工具的报告口径、未来指标优先级以此为准，
> 不用通用教练话术替代。原文照录在「个人检查清单」一节，其余按主题整理。

## 一、底层逻辑：物理限制与条件限制

- 变得更强离不开健身房：投射、进攻、速度、防守都建立在力量基础上。
- **灵活度决定投射**：踝关节、髋关节灵活度受限，肩关节过于灵活，都会影响投射；胸腔（胸椎）灵活性是关键一环。
- 地面力量转移不足、力量不足、左右力量差距，会让动态投篮（任一方向移动后出手）出问题。
- 激活练习非常具体、因人而异，没有通用模板。
- 过度弯曲、弯腰投篮是常见毛病；投篮竖起时又容易过度纠正。
- **机械投篮在实战中不实用**——运动模式中会产生新的问题。目标：fluid movers, not tight movers。

### 代偿链（最重要的一条）

- 投篮手一侧偏，是**腰部以下发生的事**导致的结果；手向外翻，是身体向左移动、手自我纠正的**补偿性运动模式**——纠正下半身才是根治，直接改手型是治标。
- 垂直核心稳定性不来自地面的基本能力时，一切都会晃。
- 右手球员过度向左旋转时（右髋开始覆盖左髋、带着胸一起拉）：胸部往哪边偏，就加强相反方向的反旋转训练。
- 胸部变紧时，保持肘部很难，肘部会开始向外旋转（诺亚系统观点：肘部伸出/肩膀紧缩，需要同时控制灵活性和力量）。
- 简易测试：双手交叉、身体微蹲、手保持在胸前——脚会代偿，但这是腰部层面（胸腔灵活性）的问题。

## 二、训练与恢复

- **一切要可追踪（everything's got to be tracked）**：防御刺激、自信度、视觉提醒（每天进步的情况、逐步认可自己在进步）、热身、工作容量（有人能在比赛强度下练 1 小时，有人只能 30 分钟）、休息恢复、睡眠。
- 呼吸：3-3 呼吸法；峰值神经刺激持续 15–20 分钟；投篮开始疲惫时就该停止。
- 以积极方式结束训练：连续命中 10 个三分收尾，增强自信。
- 中距离不能在训练中被忽视——忽视中距离会失去对篮球的控制（不是因为比赛想多打中距离）。
- 移动投篮、有目的的处理球、动态射手；学习让球移动到身体周围，而不是身体移动到球周围。
- 双球运球后退（神经过载测试：先是嘴、其次核心）；分离工作提高效率；库里式热身：脚不移动、球-眼分离、训练信息处理能力。
- 大脚趾 / 小脚趾 / 足弓；三重伸展激活（双球投篮）；离心负载处理减速部分。

## 三、接球投篮要点（wave 笔记）

- 接球就投：把球想象成烫手火球，**球去找身体**，拿到球直接收球到出手点，不要再做向下的（沉球）动作。
- 降重心靠屈髋，**不要屈膝过多**：膝关节屈过多会遏制「触地即弹」的力；正常约 1/4 蹲，自己是 1/3（偏深）。
- 右侧手脚略微向前，左肩靠后、不要抢太前的位置；接球双手平行（与脚平行），发力感知上把球「挤压」。
- 躯干不要前倾：重心向前，膝关节就会承受更大的相反力。蹬伸完身体像科比一样靠后，前脚依惯性自然伸出。
- 降速模式投篮：三步或四步。

## 四、个人检查清单（原文照录）

1️⃣ 投篮手压腕过深，限制球回到身体重心（小臂折回会有卡）
2️⃣ 出球轨迹偏头中，需要到右肩，右眼漏出
3️⃣ 习惯性重心前倾，屈膝过多，沉球过多，视线偏低等因素共同造成——踝膝髋联动的蓄力与发力，保持平衡起跳再出手，注意视线的引导，头部不要明显晃动
4️⃣ 不要持续向上推球，需要更快速度的伸肘
5️⃣ 一二步左脚蓄力多，右脚触地即弹；垫步时两个前脚掌都触地即弹
6️⃣ 保证左侧（左脚左肩）在后，随之重心也需要略靠后
7️⃣ 保持每次发力的完整性，伸膝伸髋完整，核心锁定，腿部可以自然略前摆
