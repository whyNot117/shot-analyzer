0先看这里：你该用哪种方式

两种方式用的是同一套程序，界面完全一样，区别只在于「东西跑在哪」。

方式一 · 网页版（推荐先用这个）

浏览器打开一个网址就能用，不用装任何东西。

适合：偶尔用一次、想先试试效果。

代价：第一次要联网下载识别模型（约 5–10 MB，之后有缓存）。

方式二 · 下载到本机跑

代码下载到自己电脑，用本机的 Node.js 起服务，浏览器访问 127.0.0.1:5500。

适合：内网、断网、想改代码、当成自己的小工具。

代价：要先装 Node.js（十几分钟搞定）。

两种方式都不上传你的视频。视频、身高体重、训练档案全都只留在你自己的浏览器里，关掉页面就没了。

1打开页面

方式一：直接用网页版

浏览器地址栏输入：

https://whyNot117.github.io/shot-analyzer/

回车即可。这一页会一直开着，第一次访问时它会后台下载识别模型，等一会儿就好。

方式二：本机跑起来之后

浏览器地址栏输入（端口以你终端里打印的为准，端口被占用会自动顺延）：

http://127.0.0.1:5500/

2下载到本机自己跑

只有选方式二才需要做这一节。

  1. 解压：把下载的 ZIP 解压。Windows 会多套一层 shot-analyzer-main 文件夹，把里面的内容拿出来用就行。
  2. 装 Node.js：到 nodejs.org 下载 LTS 版本，一路「下一步」装完。装完可以在开始菜单搜「PowerShell」验证： 
    node -v
    出现 v18 以上的版本号就说明装好了。
  3. 启动：在解压出来的文件夹里，双击 启动本地测试.bat。它会弹一个黑色小窗口（服务在跑），并自动打开浏览器。
  4. 手动启动也行：在文件夹里按住 Shift 右键 →「在此处打开 PowerShell 窗口」，然后敲： 
    node server.mjs
几个容易踩的坑
  • 那个黑色窗口别关——关掉服务就停了。按 Ctrl+C 也可以停。
  • 端口被占用会自动往后顺延（5501、5502…），以黑窗口里打印的地址为准。
  • 不要直接双击 index.html：浏览器禁止本地文件加载模块，页面会全是空白，一定要用上面的方式打开。
  • 本地模式不注册 Service Worker：你改了代码刷新一下就是新的，不会有旧缓存捣乱。

4看懂结果

报告

  • 分数只是筛查参考，不是命中率预测，也别跟别人的分数横向比（不同机位、不同版本口径不一样）。
  • 每个指标名后面的 ⓘ 能就地展开「它到底在量什么」，点开看白话解释。
  • 报告顶部如果有提醒（素材太远、人被挡住、只有一次出手…），先按提醒重拍，比纠结分数有用。
  • 报告结尾会写明「主体跟到第几秒」——之后画面里是别人，所以那一段没有你的骨架。

骨架叠加

  • 蓝色骨架 + 橙色关节 = 本次分析的那个人（你）。
  • 灰色骨架 = 画面里的其他人。看到灰骨架说明主体已经走出镜头，现在跟拍的是别人，不是程序坏了。

6常见问题

你看到的原因怎么办
双击 index.html 打开是空白页浏览器禁止本地文件加载 ES 模块改用 启动本地测试.bat 或 node server.mjs，地址必须是 http:// 开头
一直停在「加载识别模型中…」模型有 5–10 MB，网络慢或被限制耐心等；或改用本机版（模型在本地）
浏览器打开了但页面是旧的Service Worker 缓存按 Ctrl+F5 强刷；线上版缓存名带版本号，代码更新后会自动换
端口被占用5500 已被别的程序用服务会自动顺延，看终端打印的实际地址
没有骨架 / 没有分数素材质量预检没过（人太小、被挡住、次数太少）报告顶部会给重拍指引，按它说的重拍一次
分数忽高忽低单机位 + 只投了一次连着投 3–5 次取中位数；再补一段正面机位做融合
报告说「主体跟到 X 秒之后是其他人」你走出画面了正常提示，不是故障

7隐私：你的东西存在哪

  • 视频：只在本机浏览器里解码，程序里没有任何上传代码。
  • 身高 / 体重 / 年龄：存在本机浏览器的 localStorage，用来把身高换算成角度，出报告可以按你的身高定制。
  • 训练档案：评分历史也存在本机，导出就是给你自己的文件。
  • 唯一的网络请求是下载识别模型（MediaPipe 的 wasm 与 .task 模型文件）——那是程序本身，不是你的视频。
  • 清浏览器数据会一并清掉这些内容，重要的话记得先「⬇️ 导出」。
